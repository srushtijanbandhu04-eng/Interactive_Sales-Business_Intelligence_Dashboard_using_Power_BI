# 📊 Interactive Sales & Business Intelligence Dashboard using Power BI

## 📌 Project Overview

This project is an **interactive Sales & Business Intelligence Dashboard developed using Microsoft Power BI** with the **Adventure Works dataset**.

The dashboard transforms raw sales, product, customer, calendar, and territory data into meaningful **business insights through KPIs, DAX measures, interactive visualizations, slicers, and page navigation**.

The primary objective is to help users quickly understand **sales performance, revenue, profitability, customer activity, product performance, and regional business trends** through an intuitive and interactive dashboard.

---

## 🎯 Project Objectives

* Analyze overall **sales and revenue performance**
* Monitor important **business KPIs**
* Analyze **profit and profit margin**
* Compare performance across different **regions and countries**
* Analyze product and category performance
* Track **orders, units sold, and customers**
* Perform **monthly and previous-month analysis**
* Create an interactive dashboard using **Power BI and DAX**
* Convert raw business data into **actionable insights**
